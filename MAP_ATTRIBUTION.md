# Map and data attribution

## OpenStreetMap
This prototype displays map tiles from OpenStreetMap when an internet connection is available.

© OpenStreetMap contributors

OpenStreetMap data is available under the Open Data Commons Open Database License (ODbL). The public tile service is used only for currently visible tiles, with local caching and an identifying User-Agent. Production releases should move to a dedicated tile provider or self-hosted tiles if traffic grows.

## Port coordinates
Port markers are geographic reference points used for gameplay and may be refined as the simulation expands.
